About

KTCurses is a small, opinionated CLI library for Kotlin, created by Yuun.

It was built out of a desire for a terminal UI library that doesn't get in the way. No massive build configurations, no transitive dependency hell — just clean, readable Kotlin code that does exactly what you tell it to.

Why?

Why one file? Because it forces simplicity. Everything lives in KTCurses.kt. You can read the entire source code in a few minutes. If you need to tweak something, you just edit the file. No forking, no PRs to a dead repo.

Why no dependencies? Because your terminal app shouldn't need 50MB of third-party libraries just to draw a box and read a key press. It uses pure JDK and Kotlin standard library.

Why diff-based rendering? Because flicker is ugly. KTCurses keeps a back buffer and only redraws the cells that actually changed since the last frame. It's fast, smooth, and easy on the eyes.
