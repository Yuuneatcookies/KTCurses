KTCurses

A small CLI library for Kotlin. True color, diff-based rendering, and a simple canvas API. In one FILE.

Installation

KTCurses is distributed as a standalone JAR. Download the latest version from the Releases page.

build.gradle.kts 
// build.gradle.kts
dependencies {
    implementation(files("libs/ktcurses-v0.1.0.jar"))
}

Quick Example

The main entry point is the ktcurses block. It handles terminal setup, rendering, and cleanup automatically.

main.kt 
import ktcurses.*

fun main() = ktcurses(mouse = true) { screen ->
    while (true) {
        screen.render {
            clear()
            box(1, 1, width - 2, height - 2, Border.Rounded, title = " app ")
            text(3, 3, "Hello, TUI!", Style(fg = Color.Cyan, attrs = Attrs.Bold))
        }
        when (val e = screen.waitEvent()) {
            is KeyEvent -> if (e.key == Key.Escape) return@ktcurses
            else -> {}
        }
    }
}

Screen

Manages the terminal state, input queue, and the render loop. The Screen class is responsible for switching to the alternate screen buffer, putting the terminal into raw mode, and handling cleanup on exit.

render(draw: Canvas.() -> Unit) +

Clears the back buffer, runs your drawing block, and flushes only the cells that have changed since the last frame. This diff-based rendering ensures high performance and zero flicker.

waitEvent(): Event +

Blocks the current thread until an input event arrives. It reads from a thread-safe queue that is populated by a background input reader thread. This is the recommended way to handle input in a game loop or event-driven app.

poll(timeoutMs: Long): Event? +

Non-blocking (or semi-blocking) alternative to waitEvent. Waits for up to timeoutMs milliseconds. Returns null if no event arrived. Useful for animations where you need to update the screen even without input.

Canvas

Provides the drawing primitives. A Canvas instance is passed to the render block and automatically handles wide characters (CJK, emoji) and clipping bounds.

text(x, y, s, style) +

Draws a string starting at (x, y). Returns the x-coordinate after the last drawn character. Automatically handles Unicode wide characters (e.g., Chinese characters take up 2 cells).

gradient(x, y, s, from, to) +

Draws text where the foreground color smoothly transitions from from to to across the length of the string. Requires TrueColor to look good.

box(x, y, w, h, border, title) +

Draws a rectangular border. You can pass a custom Border (Single, Rounded, Double, Heavy, Ascii) and an optional title string.

bar(x, y, w, value, filled) +

Draws a progress bar. It uses partial block characters (▏▎▍▌▋▊▉) to provide sub-cell precision, making the progress smooth even on small widths.

Events & Input

Input is read on a background daemon thread and parsed from raw ANSI escape sequences. All events are pushed to a thread-safe queue. You consume them using Screen.waitEvent() or Screen.poll().

KeyEvent

Represents a single key press. The parser handles standard ASCII, UTF-8 (for international characters and emoji), and standard terminal escape sequences (CSI/SS3) for arrows and function keys.

Properties:

  • key: The pressed key (Key.Up, Key.Enter, Key.rune('a'.code), etc.).
  • ctrl, alt, shift: Modifier booleans.
  • char: The actual character (if applicable), or null for special keys.
input.kt 
when (val e = screen.waitEvent()) {
    is KeyEvent -> {
        if (e.ctrl && e.key == Key.rune('c'.code)) {
            // Ctrl+C pressed
        } else if (e.key == Key.Escape) {
            // Esc pressed
        }
    }
}

MouseEvent

Triggered when the user interacts with the mouse. Mouse support is enabled by passing mouse = true to the ktcurses block. The library uses SGR 1006 mouse mode for maximum compatibility.

Properties:

  • x, y: Zero-based coordinates.
  • button: Left, Middle, Right, WheelUp, WheelDown.
  • action: Press, Release, Drag, Scroll.

ResizeEvent

Fired when the terminal window is resized. KTCurses listens for the SIGWINCH signal (on POSIX systems) or polls stty size as a fallback. When a resize happens, the internal grid is automatically reallocated before you receive the event.

Colors & TrueColor

KTCurses supports three color modes, detected automatically via ColorMode.detect():

  • None: No colors (if NO_COLOR is set or TERM=dumb).
  • Ansi256: The standard 256-color palette.
  • TrueColor: 24-bit RGB (16.7 million colors).

Why TrueColor?

Standard terminals only supported 16 or 256 colors. If you wanted a specific shade (like GitHub's dark background #0d1117), the terminal would snap it to the nearest color in its fixed palette.

TrueColor (24-bit) allows you to specify exact RGB values, just like in CSS or Photoshop. KTCurses uses the \e[38;2;R;G;Bm escape sequence for foreground and \e[48;2;R;G;Bm for background.

If the terminal doesn't support TrueColor, KTCurses automatically degrades gracefully: the to256() function finds the closest matching color in the 256-color palette, so your app still looks correct.

colors.kt 
// Exact 24-bit RGB colors
val customStyle = Style(
    fg = Color.rgb(255, 192, 203), // Pink
    bg = Color.hex(0x0d1117),      // GitHub dark bg
    attrs = Attrs.Bold or Attrs.Underline
)

// Smooth gradients
canvas.gradient(5, 5, "Gradient Text", Color.Cyan, Color.Magenta)
