# Contribute To KTCurses
> im yuun, and thanks for taking the time to contribute and read!

## how to, contribute!

### ***bugs***
> if you found a 🐛bug🐛, open an issue and include:

- **Your OS:** [![Linux](https://img.shields.io/badge/Linux-lightgrey?style=flat-square&logo=linux&logoColor=black)](https://kernel.org) [![macOS](https://img.shields.io/badge/macOS-lightgrey?style=flat-square&logo=apple&logoColor=black)](https://apple.com) [![BSD](https://img.shields.io/badge/BSD-red?style=flat-square&logo=freebsd&logoColor=white)](https://freebsd.org) [![Hurd](https://img.shields.io/badge/GNU%20Hurd-lightgrey?style=flat-square&logo=gnu&logoColor=black)](https://gnu.org)
- **Terminal:** [![Konsole](https://img.shields.io/badge/Konsole-lightgrey?style=flat-square&logo=gnome-terminal&logoColor=black)](https://konsole.kde.org) *(or any other)*
- **KTC version**
- **Minimal code-example that reproduces the bug.**

All bugs are reviewed and fixed from one hour to a week. (No promises, but I try to be fast).

### ***new ideas***
> you can write a new idea. but: **no dependencies**. Only standard [![Temurin](https://img.shields.io/badge/Temurin-lightgrey?style=flat-square&logo=eclipse&logoColor=black)](https://adoptium.net) and [![Kotlin](https://img.shields.io/badge/Kotlin-lightgrey?style=flat-square&logo=kotlin&logoColor=black)](https://kotlinlang.org) imports.

### ***forks***
> If you fork the repo and add something new, that's cool. But if you break it, *Im can To get rid of it*.
